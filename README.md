# OpenGuessr-Enhancer

**OpenGuessr Enhancer** is a lightweight browser extension that reveals the exact location in [OpenGuessr](https://www.openguessr.com).  
Useful for debugging, map-making, or just satisfying your curiosity.

---

## Features

- Gives you the location details!
- Shows the exact latitude and longitude of the current round
- Works in single-player AND multiplayer.

---

## Installation

### For Chrome, Edge, Brave, and other Chromium-based browsers

1. Download the latest source code as a ZIP file
2. Extract the ZIP (Use Extract Here) to a folder on your computer
3. Open your browser and go to: `chrome://extensions/`
4. Enable **Developer mode** (toggle in the top-right corner)
5. Click **Load unpacked**
6. Select the folder you extracted

The extension should now appear in your toolbar.

---

### For Firefox

1. Download the source code and extract it to a folder
2. Open Firefox and go to: `about:debugging#/runtime/this-firefox`
3. Click **"Load Temporary Add-on..."**
4. Select any file from the extracted folder (e.g. `manifest.json`)

> ⚠️ Temporary add-ons are removed when you close Firefox.  
> For a permanent install, you’ll need to package and sign the extension through [addons.mozilla.org](https://addons.mozilla.org/) (AMO).

---

## Usage

1. Load [OpenGuessr](https://www.openguessr.com)
2. The exact location will be revealed, along with an option to open the location in Google Maps.
