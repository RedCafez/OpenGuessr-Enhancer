# OpenGuessr Enhancer

This extension shows you the exact location in [OpenGuessr](https://www.openguessr.com).  
Useful if you're making maps, testing stuff, or just curious where the heck you are.

## Features

- Shows latitude + longitude
- Button to open in Google Maps
- Works in Single & Multiplayer
- Super lightweight

---

## Install

### Chrome / Edge / Brave

1. Download the zip
2. Unzip it
3. Go to `chrome://extensions`
4. Turn on “Developer mode”
5. Click “Load unpacked”
6. Pick the folder you unzipped

Done.

---

### Firefox

1. Unzip the folder
2. Go to `about:debugging#/runtime/this-firefox`
3. Click “Load Temporary Add-on”
4. Select any file (like `manifest.json`)

Note: It’ll get removed when you close Firefox
